## 2. Origin of Warnings: React 19 Production DOM Reconciler

The 4 warnings originate exclusively from the standard **React 19 (`react-dom@19.0.0`)** client runtime bundled into the extension's standalone pages (`options/options.js` and `popup/popup.js`):

1. **Reconciler Reset**: React's internal fiber reconciler (`react-dom/client`) contains routines for clearing child DOM nodes:
   ```javascript
   // React 19 internal container cleanup:
   node.innerHTML = '';
   ```
2. **Untouched Runtime Code**: We deliberately preserve the pristine, untampered production bundle generated by `esbuild` rather than executing brittle post-build regex rewrites (e.g., replacing `.innerHTML` with `.textContent`). Post-build regex replacement risks breaking internal framework assumptions or obscuring code provenance.

## 3. Extension Security & DOM-XSS Immunity

Currency Convertr operates under strict security policies documented in the repository's Architectural Decision Records (**ADR 0008: Zero innerHTML & XSS Prevention** and **ADR 0014: UI Stack for Extension Pages**):

1. **Zero `innerHTML` in Extension Code**:
   - `innerHTML`, `outerHTML`, `insertAdjacentHTML`, and React's `dangerouslySetInnerHTML` are **strictly prohibited** in all first-party application source code.
   - All DOM creation across options (`src/options/`), popup (`src/popup/`), and shared components (`src/ui/`) is performed via native DOM APIs:
     - `document.createElement()`
     - `document.createTextNode()`
     - `element.textContent = ...`
     - `element.replaceChildren()`
     - `document.createElementNS('http://www.w3.org/2000/svg', ...)`
2. **Vanilla Boundary for Host-Page Content Scripts**:
   - `src/content/content.js`, `src/content/scanner.js`, and `src/content/ui.js` are **100% pure vanilla JavaScript**.
   - Neither React nor any third-party framework is ever injected into user web pages.
   - In-page DOM mutations occur strictly inside an open Shadow DOM (`#currency-converter-pill-host`) or inline price replacements using sanitized `document.createElement('span')` and `document.createTextNode()`.
3. **No External Network Code / Strict CSP**:
   - The extension requests **zero remote scripts** or stylesheets.
   - All fonts (Familjen Grotesk, Fragment Mono) are packaged locally as WOFF2 files.
   - Extension CSP strictly enforces `script-src 'self'`, preventing any remote script injection or `eval` usage.

## 4. How to Reproduce and Build from Source

To reproduce the exact distribution bundle and verify `web-ext lint`:

```bash
# 1. Clone repository
git clone https://github.com/richmondsogo/currency-converter-v2.git
cd currency-converter-v2

# 2. Install dependencies
npm ci

# 3. Build distribution packages (esbuild)
npm run build

# 4. Verify with Mozilla Web-Ext Linter
npm run lint:firefox
```

The compiled Firefox extension bundle will be located at:
- Unpacked directory: `dist/firefox/`
- Submission ZIP archive: `dist/packages/currency-converter-firefox-v2.0.0.zip`
